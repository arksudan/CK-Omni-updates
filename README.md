# CK Omni — updates

This repository only hosts signed update packages for **CK Omni**.

CK Omni is private software. It may be used only by people the developer has authorized
with a valid serial key. Downloading or using these files without that authorization is not permitted.

The source code is not published here. It may be made public in the future, but not at this time.

Installed copies of CK Omni fetch their updates from this repository automatically
(Help > Check for Updates). Every package is signed by the developer, and the app refuses
anything that isn't.
